# Agent Data

Agent data files for the AWS Cloud Engineer roadmap project.

## Data Directory

```
.kilo/data/
```

## Purpose

This directory stores data files that agents can reference during task execution. Currently empty.

## Usage

Add data files here when agents need persistent reference data beyond memory and skills. Examples:
- JSON/YAML configuration snippets
- Reference tables
- Template data
- Asset manifests

## Adding New Data

1. Add data file to `.kilo/data/`
2. Reference from skills or memory as needed
3. Keep files small and focused
