# Agent Metadata

Agent metadata for the AWS Cloud Engineer roadmap project.

## Meta Directory

```
.kilo/meta/
```

## Purpose

This directory stores metadata about agent configuration and state.

## Contents

- Agent configuration versions
- Feature flags
- Operational notes
- Validation results

## Usage

Metadata is read by agents to understand configuration state and operational constraints.

## Adding New Metadata

Add metadata files here when tracking agent-specific configuration state that doesn't belong in skills, memory, or data.
