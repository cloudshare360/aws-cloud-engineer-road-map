# AWS Cloud Engineer Roadmap

## Overview

This repository contains the complete roadmap, learning path, and engagement framework for an **AWS Cloud Engineer** committed role. The associate is positioned as a **mid-level developer with 6 years of experience**, supported by a technical expert layer to ensure successful task execution.

## Quick Summary

### 20-Week Learning Roadmap
1. **Weeks 1-4** — Backend Foundations (JavaScript, TypeScript, Node.js, Express.js, REST APIs, Python)
2. **Weeks 5-8** — Testing & Marketing (Jest, Chai, Mocha, Sinon, portfolio development)
3. **Weeks 7-8** — Frontend Basics (Angular, Karma, ReactJS)
4. **Weeks 9-12** — Hands-on AWS Services (Lambda, API Gateway, DynamoDB, SNS, SQS, SES, Step Functions, S3, RDS, OpenSearch, Athena, AppSync, EC2, Docker, ECS, EKS, IAM, Secrets Manager, CloudWatch, X-Ray)
5. **Weeks 13-14** — Infrastructure as Code (AWS CDK, CloudFormation, Terraform)
6. **Weeks 15-16** — CI/CD & DevOps (GitLab, GitHub, Jenkins)
7. **Weeks 17-20** — Angular Development (Core + Advanced)
8. **Client-driven** — React/Next.js alternative path

### Three-Party Engagement Model
- **Employer (Client)** — Provides requirements, access, and feedback
- **Vendor (Training/Support Company)** — Supplies the associate and expert support layer
- **Associate (6 YOE Mid-Level Engineer)** — Delivers development tasks with expert backup
