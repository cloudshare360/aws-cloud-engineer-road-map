AWS Cloud Engineer

33-Week Learning Roadmap — From Fresher to Full-Stack AWS Cloud Serverless Engineer

Learning Overview

This program transforms a fresher with no programming background into a job-ready AWS Cloud Engineer (entry-to-mid level, 0-3 YOE) through a structured 33-week curriculum. The path uses four parallel tracks that run simultaneously from Day 1:

Four Parallel Learning Tracks

Track A: Fullstack
MEAN/MERN, Python, Java, .NET, Angular, React, Vue
Track B: Git & Tooling
Git/GitHub, VS Code, Codespaces, Markdown, GitHub Pages
Track C: CI/CD & DevOps
GitHub Actions, GitLab CI, Jenkins, automated pipelines
Track D: Agile & Process
Scrum, Kanban, sprints, task-based learning, progress tracking

33-Week Training Roadmap

Weeks 1-4 MEAN Stack (MongoDB, Express, Angular, Node.js) + Git/CI/CD foundations
Weeks 5-8 MERN Stack (MongoDB, Express, React, Node.js) + Portfolio/advanced Git
Weeks 9-10 Python (Flask, FastAPI, boto3) + Monorepo/build automation
Weeks 11-12 Java (Spring Boot) + Docker in CI/CD
Weeks 13-14 .NET/C# (ASP.NET Core) + Infrastructure as Code basics
Weeks 15-17 Testing (Jest, Mocha, Cucumber, Playwright) + test automation
Weeks 18-21 Frontend Mastery (Angular, React/Next.js, Vue.js) + frontend CI/CD
Weeks 22-25 AWS Core (Lambda, API Gateway, DynamoDB, S3, RDS, SNS/SQS/SES, Step Functions)
Weeks 26-29 AWS Advanced (EC2, Docker, App Runner, ECS, EKS, CloudWatch, X-Ray)
Weeks 30-31 IaC (CloudFormation, AWS CDK, Terraform, OpenTofu)
Weeks 32-33 CI/CD & DevOps (GitLab CI, Jenkins, GitHub Actions, Blue/Green deploy)

Key Highlights

  • Target Audience: Fresher from college with NO programming background
  • Duration: 33 Weeks (~8-9 months)
  • Engagement Type: Committed, full-time role with long-term growth path
  • Support Model: Technical expert layer for architectural guidance, code reviews, and gap remediation
  • Training: Structured 33-week learning roadmap with weekly milestones
  • Delivery: MEAN/MERN first, then Python/Java/.NET, then AWS cloud, then multi-cloud expansion
  • Learning Model: Four parallel tracks — Fullstack, Git/IDE, CI/CD, Agile
  • Tools: Node.js, Express.js, Python, Angular/React/Vue, AWS CDK, Terraform, OpenTofu, GitLab/GitHub/Jenkins
